# L10n (Localisation)

## Purpose

Internationalisation resources and generated localization delegates.

## Contents

- `app_en.arb` - English string catalogue (source of truth).
- `app_localizations.dart` - Generated base localisation class and delegate.
- `app_localizations_en.dart` - Generated English implementation.
- `l10n_extension.dart` - `AppLocalizationsX` extension providing `context.l10n` convenience getter.

## Dependencies

- `flutter_localizations` SDK package
- `intl` for message formatting

## Usage

Access strings in widgets via:

```dart
// Preferred: Use the extension
Text(context.l10n.marketsTitle);

// Alternative: Direct access
final l10n = AppLocalizations.of(context);
Text(l10n.marketsTitle);
```

## Architecture Notes

- Only `app_en.arb` is manually edited; the Dart files are auto-generated by `flutter gen-l10n`.
- The generated files are excluded from static analysis in `analysis_options.yaml`.
- Adding a new locale requires creating `app_<locale>.arb` and re-running code generation.
